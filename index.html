Foundations first, then AppSec core, then cloud security, then the AI-augmented and portfolio phases that turn all of it into a job application. Every built day is fully interactive — click in and work through it.

// WHY THIS EXISTS
Three things, not forty

Every day in this roadmap ships with the same three pieces, built to the same bar, every time.

🧪
Interactive, not passive
Live SQL injection terminals, an actual Burp Suite simulator you can type into, a clinical XSS lab — each day's lesson is themed to its subject and built to be operated, not just scrolled past.
📋
Full-depth revision notes
Every day gets a standalone note: one-sentence summary, deep-dive sections, a self-test with full answers, and a quick-reference card — built for the night before an interview, not just the day you learned it.
🎯
Built for the actual interview
62 flashcards covering tools, Git, and the first four days in depth — drilled the way real technical interviews actually ask, not generic trivia.
