MODULE 03 // REGEX

Find Patterns in Chaos

Regex is a metal detector. Point it at text, it finds what matches.

Regex (Regular Expressions) is a pattern-matching language. You write a pattern. Python checks if text matches that pattern. Security engineers use it constantly to extract data from logs, responses, and source code.

Essential regex patterns for security work:
\d — any digit (0–9)
\w — any word character (a-z, A-Z, 0–9, _)
\s — whitespace
. — any character (except newline)
+ — one or more of previous
* — zero or more
? — zero or one (optional)
{3} — exactly 3 of previous
^ — start of string  |  $ — end of string
[] — character class: [a-z] = any lowercase letter
() — capture group: extract this part

MODULE 04 // FILE I/O

Read Targets. Save Results.

Every security tool reads input from files and saves output to files.

You'll never type targets by hand when you have 500 of them. You'll never let results scroll off-screen. File I/O is the glue that makes tools scalable.

file_patterns.py — security tool I/O

"w" vs "a" — when to use which:
open("results.txt", "w") = OVERWRITE. Fresh start every run. Good when you want clean output per scan.
open("results.txt", "a") = APPEND. Keeps previous results. Good when you scan over time and don't want to lose history.
Same choice as > vs >> in Linux (Day 2).
